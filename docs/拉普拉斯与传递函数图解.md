## 1. 为什么要拉普拉斯变换

系统（电机、电流环）有**记忆**：电感储能、积分累积，t 时刻的输出取决于过去所有输入。所以：

- 时域里"输出 ÷ 输入"随时间、随输入而变，不能代表系统
- 时域里描述系统的是**冲激响应 g(t)**（静止时敲一下，之后自己的运动），但输出 = g 与输入的**卷积**，难算、不能相除

拉普拉斯变换的作用：

| 时域 | s 域 |
|---|---|
| 求导 | 乘 s（初值为 0） |
| 积分 | 除以 s |
| 卷积 y = g * x | 乘法 Y = G·X |
| 微分方程 | 代数方程 |

所以"输出 ÷ 输入 = 系统本身"只在 s 域成立：**G(s) = Y(s)/X(s)，它就是 g(t) 的拉氏变换**。

## 2. 两个变量：t 和 s

```
F(s) = ∫₀^∞ f(t)·e^(−st) dt         s = σ + jω
```

| | t | s |
|---|---|---|
| 是什么 | 时间，回答"什么时候" | 复频率，回答"哪种运动模式" |
| 单位 | 秒 | 1/秒 |
| 关系 | 两者独立；积分把 t 积掉，只剩 s | |

**每个 s 代表一种波形 e^(st) = e^(σt)·e^(jωt)**：σ 是衰减/增长速率，ω 是振荡角频率。

| s | e^(st) | 例子 |
|---|---|---|
| 0 | 常数 | 稳态，G(0) |
| −1/τ = −3650 | 指数衰减 | 电机自然响应 |
| j·6283 | 1 kHz 等幅正弦 | 带宽、相位裕度 |
| −1000 ± j·20100 | 3.2 kHz 衰减振荡 | 3 kHz 带宽时的振铃 |

**自变量要分清**：在 e^(st) 里 t 是自变量、s 是参数（挑选哪个信号）；在 F(s)、G(s) 里 s 是自变量、t 已经没了。

## 3. 核心图像：探针、箭头、积分轨迹

### 3.1 复数 = 平面上的箭头

- 加减：首尾相接（向量加法）
- 乘以 r·e^(jθ)：长度乘 r，逆时针转 θ
- 乘 j：转 90°；除以 j（乘 −j）：转 −90°；乘 −1：转 180°
- 代数上把 j 当成满足 j² = −1 的符号来算；几何上 j 是"垂直方向"，不是距离
- 分母有 j：1/j = −j；一般复数分母乘共轭；或用极坐标（长度相除、角度相减）

### 3.2 e^(jωt) = 单位圆上匀速转圈的箭头

- 长度恒为 1（"等幅"），角速度 ω
- 实数 cos(ωt) = 一对反向转动的箭头 ½e^(jωt) + ½e^(−jωt)，虚部抵消
- 系数是实数时，实部只产生实部：用 e^(jωt) 算完取实部 = 真实的 cos 输入的输出

### 3.3 乘积 f(t)·e^(−st)：按转速拆成箭头首尾相加

乘以探针 = 每个箭头额外倒转 ω、长度再乘 e^(−σt)。信号的成分 c·e^(pt) 乘以探针后变成 c·e^((p−s)t)。

**不要拆成实部 + 虚部，要按转速拆成箭头**：实部 + 虚部是沿固定轴投影，会把静止和转动的部分混在一起。

### 3.4 两种箭头的积分（先积到 T，再看 T → ∞）

| 箭头 | ∫₀ᵀ | 轨迹 | T → ∞ |
|---|---|---|---|
| 静止 c | c·T | 沿 c 的方向一直走 | → ∞，**极点** |
| 转动 c·e^(jω₀t) | (c/jω₀)·e^(jω₀T) − c/jω₀ | 绕圆心 −c/(jω₀) 转，半径 \|c\|/\|ω₀\|，经过原点，比原箭头落后 90° | 一直绕圈，有界 |
| 边转边缩短 c·e^(qt)，Re q < 0 | (c/q)(e^(qT) − 1) | 螺旋收缩 | 收敛到 −c/q |

- 转一圈指向各方向时间相同，面积抵消，所以转动箭头积分有界
- 转得越慢圈越大；转速为 0 时圈拉直成射线 = 静止箭头
- 积分可以拆开分别算再相加（线性），但要先在有限 T 上拆，再取极限
- **F(s) = 各箭头积分后的圆心（极限点）之和**

### 3.5 探针放在 s 平面不同位置（信号极点 p = −0.3 ± 2.5i）

| 探针位置 | 乘积里的箭头 | 积分 | 山峰图高度 \|F(s)\| |
|---|---|---|---|
| 正好在极点 | 一个静止（方向 = 初相位 φ）+ 一个转动 | 一边绕小圈一边沿 φ 方向走，→ ∞ | ∞（柱子） |
| σ = −0.3，ω ≠ ±2.5 | 都在转，长度不变 | 绕 F(s) 打圈 | 圆心到原点的距离 |
| σ > −0.3（收敛域） | 都在转、越来越短 | 螺旋收敛到 F(s) | 积分的极限 |
| σ < −0.3 | 越来越长 | 发散 | 公式延拓值，不是积分结果（不用管） |

静止箭头可以斜着：cos 时在实轴，sin 时在负虚轴，45° 相位时沿 45° 走。

### 3.6 s 平面山坡图

- 高度 = |F(s)|（复数的长度），角度没画
- **柱子 = 极点**：信号确实含有这个成分 e^(pt)；柱子都无穷高，成分多少看部分分式的系数
- **山坡没有独立信息**，只表示离柱子多近
- **坑 = 零点**：各成分贡献正好抵消的位置
- 沿虚轴切一刀 = 傅里叶频谱 / 频率响应。频谱峰 ≈ 极点在虚轴上的"影子"：峰位置 ≈ 极点虚部，半功率带宽 = 2 × 极点实部，阻尼越小峰越尖

## 4. 极点与零点

| | 信号 F(s) | 传递函数 G(s) |
|---|---|---|
| 极点 | 信号含有的运动模式（衰减速率 + 频率） | 系统自然响应的模式（G 是冲激响应的变换） |
| 零点 | 各成分在此抵消；位置随成分的份量和相位变化（改 φ 极点不动、零点移动） | 系统完全挡住的输入模式 e^(zt) |

- 极点在左半平面 → 自然响应衰减 → 稳定；离虚轴越近衰减越慢；虚部越大振荡越快
- **主导极点**：离虚轴最近的，最后剩下的响应由它决定
- 输出 Y = G·X 的极点 = G 的极点（自然响应）+ X 的极点（强迫响应）
  - 例外 1：零点与极点对消，该极点消失（PI 零点对消电机极点）
  - 例外 2：输入极点与系统极点重合 → 重极点 → t·e^(pt)，共振
- 有限个成分组成的信号/系统：**极点 + 零点 + 比例系数**完全确定 F(s)

**自然响应 vs 强迫响应**：总响应 = 强迫响应（跟着输入的形状，来自 X 的极点）+ 自然响应（系统自己的模式，来自 G 的极点，形状 e^(pt)，就像钟的音调与敲法无关）。暂态消失 = 自然响应衰减完，此后才能用 G(0)、G(jω) 计算输出。

## 5. 传递函数怎么用（三个特殊点）

| 想知道 | 代入 | 条件 | 读出 |
|---|---|---|---|
| 恒定输入的最终值 | s = 0 | 系统稳定 | G(0) = 稳态输出 ÷ 输入 |
| 正弦输入的响应 | s = jω | 系统稳定、暂态消失 | 幅度 × \|G(jω)\|，相位转 ∠G(jω) |
| 自然响应、稳定性 | 分母 = 0 | — | 极点位置 |

- 常数 = e^(0·t)，所以看 G(0)；正弦 = e^(±jωt)，所以看 G(jω)
- \|G(jω)\| 是两个正弦的**峰值之比**，不是同一时刻的瞬时值之比（还有相位差）
- Bode 图 = 频率响应 G(jω) 的画法：上图幅度（dB = 20·log₁₀|G|），下图相位（负 = 落后）
- 线性时不变才能用：只含乘常数、加减、求导、积分、延迟；两个信号相乘、限幅、死区都是非线性

## 6. 在电机和电流环里

| 对象 | 传递函数 | 极点 / 零点 | 意义 |
|---|---|---|---|
| 电机（不转，一相/一轴） | G_m = 1/(Ls + R) | 极点 −R/L = −3650 | 自然响应 e^(−t/0.27ms)；G_m(0) = 1/R；带宽 R/(2πL) = 580 Hz |
| PI | Kp + Ki/s = (Kp·s + Ki)/s | 极点 0（积分），零点 −Ki/Kp | 零点放在 −R/L 上对消电机极点 |
| 延迟 | e^(−s·Td) | — | 幅度 1，相位落后 ω·Td |
| 环路 | G_L = PI × 延迟 × 电机 = (ω_bw/s)·e^(−s·Td) | 积分极点 0 | 在 \|G_L\| = 1 处看相位裕度（63°） |
| 闭环 | G_cl = G_L/(1+G_L) ≈ ω_bw/(s + ω_bw) | 极点 −ω_bw = −6283 | G_cl(0) = 1 无稳态误差；带宽 1 kHz；时间常数 0.16 ms |

- 3 kHz 带宽时闭环极点约 −1000 ± j·20100，靠近虚轴 → 3.2 kHz 振铃、衰减慢（Simulink 实测吻合）
- PI 电流环 ≈ 弹簧质量阻尼系统：L ↔ 质量，R + Kp ↔ 阻尼，Ki ↔ 刚度

## 7. 只记规则、暂缓推导

| 内容 | 怎么用 |
|---|---|
| 欧拉公式 e^(jθ) = cos θ + j·sin θ | 直接用 |
| 逆变换积分公式 | 部分分式 + 查表；或 MATLAB `ilaplace`、`step`、`impulse`、Simulink |
| 收敛域外的值（解析延拓） | 公式在整个平面都能用，不管积分是否收敛 |
| 冲激函数 δ(t)、卷积定理的证明 | 记住"时域卷积 = s 域相乘"、"G 是冲激响应的变换" |
| 复变函数性质、留数定理 | 不需要 |

常用变换对：

| 时域 | s 域 |
|---|---|
| 1（阶跃） | 1/s |
| t（斜坡） | 1/s²（每多除一个 s，时域多积分一次） |
| e^(−at) | 1/(s+a) |
| t·e^(−at) | 1/(s+a)²（重极点 → t 倍成分） |
| e^(−at)·sin(ωt) | ω/((s+a)² + ω²) |
| e^(−at)·cos(ωt) | (s+a)/((s+a)² + ω²) |
| δ(t)（冲激：极窄极高、面积 1，"一下子给完"） | 1 |
