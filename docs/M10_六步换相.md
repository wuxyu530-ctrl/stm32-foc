# M10：六步换相（编码器模拟霍尔）

> 2026-11-06 设计与实现，2026-11-07～08 周末上板。

---

## 1. 做法

电机没有霍尔，用编码器电角度模拟：每个中断算出 θe，判断在哪个 60° 扇区，按表导通两相、第三相悬空。

```
扇区 s = floor((θe + 30°) / 60°)，s = 0 对应 θe ∈ [−30°, 30°)

 s  │ θe 范围        │ 进（上管 PWM） │ 出（下管常开） │ 悬空 │ 电流矢量方向
────┼───────────────┼──────────────┼──────────────┼─────┼──────────
 0  │ −30° ～  30°   │ B            │ C            │ A   │  90°
 1  │  30° ～  90°   │ B            │ A            │ C   │ 150°
 2  │  90° ～ 150°   │ C            │ A            │ B   │ 210°
 3  │ 150° ～ 210°   │ C            │ B            │ A   │ 270°
 4  │ 210° ～ 270°   │ A            │ B            │ C   │ 330°
 5  │ 270° ～ 330°   │ A            │ C            │ B   │  30°
```

电流矢量始终超前转子 60°～120°（平均 90°）。

**定时器怎么实现三种状态**（`main.c` 的 `sixstep_apply()`）：

| 相的状态 | 做法 |
|---|---|
| 进 | 互补 PWM，CCR = D × ARR（上管导通 D，其余时间下管续流） |
| 出 | 互补 PWM，CCR = 0（上管不开，下管常开） |
| 悬空 | 清 CCxE、CCxNE，并置 BDTR.OSSR = 1：上下管都输出无效电平（都关） |

只在换相时改 CCER；退出六步时三相输出全部重新使能。

## 2. 上板流程（`APP_MODE = APP_M10_SIXSTEP`）

| 步骤 | 内容 | 串口输出 |
|---|---|---|
| ①～④ | 同 M7 | 同 M7 |
| ⑤a | 切到六步换相，占空比 0.08 / 0.12 / 0.16 / 0.20 / 0.24 逐档，每档等 0.7 s 再测 0.8 s | `duty, rpm, iq_mean_A` 五行 |
| ⑤b | 最后一档：按电角度分箱平均 2 s + 原始波形 40 ms | — |
| ⑤c | 无缝切到 FOC 速度环，目标 = 六步测得的转速（预置 vq = 反电动势，避免切换冲击），同样分箱平均 2 s + 原始波形 40 ms | `[5c] FOC at ... rpm` |
| ⑥ | 打印四段数据，iq = 0 滑行后停 | `SIXSTEP BINS`、`SIXSTEP`、`FOC BINS`、`FOC` |

**为什么要分箱平均**：空载时稳态电流只有约 25 mA，而单次采样噪声约 ±120 mA，原始波形看不清。
按电角度每 5° 一箱、跨约 140 圈电角度取平均，每箱约 500 个点，噪声降到约 ±5 mA。

## 3. 预期

**转速 vs 占空比**（粗估：D × 12 V − 2R·I ≈ 线反电动势在导通区间的平均值 1.65 × ωe × ψf）：

| 占空比 | 0.08 | 0.12 | 0.16 | 0.20 | 0.24 |
|---|---|---|---|---|---|
| 估算转速 (rpm) | ~190 | ~310 | ~430 | ~550 | ~670 |

死区会让实际电压偏小，实测转速会低一些。

**电流波形**（看分箱平均那两段）：

| | 六步换相 | FOC |
|---|---|---|
| 三相电流 | 方波状：每相导通 120°、悬空 60°，导通时正负交替 | 正弦波，三相相差 120° |
| iq（正比于转矩） | 每 60° 电角度一个周期的起伏，换相处有尖峰 | 基本是一条平线（约 25 mA） |

这就是"同一个电机、同一块板子，六步换相和 FOC 的转矩脉动对比"。

## 4. 安全

- 2 A 软件过流保护照常有效；转速超过 1500 rpm 立即停
- 如果扇区表或方向不对，电机可能不转、抖动或反转：⑤a 打印的转速会接近 0 或为负，**看到就断电**，把数据发给我
- 堵转时电流约 D × 12 V ÷ (2 × 3.21 Ω)，最大档约 0.45 A，短时间没问题

## 5. 首次上板结果（2026-11-07，电机手按，`data/m10_sixstep_vs_foc.txt`）

**转速 vs 占空比**：和估算基本一致，线性很好（约 2900 rpm / 单位占空比）

| 占空比 | 0.08 | 0.12 | 0.16 | 0.20 | 0.24 |
|---|---|---|---|---|---|
| 估算 (rpm) | ~190 | ~310 | ~430 | ~550 | ~670 |
| **实测 (rpm)** | **211** | **328** | **445** | **561** | **677** |
| 平均 iq (mA) | 17 | 18 | 20 | 21 | 22 |

**无扰切换到 FOC**：目标 677.0 rpm，实测 675.8 rpm，切换过程没有过流。

**转矩电流 iq 的脉动**（按电角度分箱平均，每箱约 550 点；再把 6 个扇区叠到一个 60° 区间里）：

```
距上次换相的电角度：   0°    10°   20°   30°   40°   50°   60°
六步 iq (mA)：       27.5  29.8  19.0  10.2  13.4  29.2  41.1   ← 扇区两头高、中间低
FOC  iq (mA)：       23.4  23.4  22.3  23.0  24.3  24.1  22.9   ← 基本是平的
```

| | iq 平均 | 整圈标准差 | 整圈最小 ～ 最大 |
|---|---|---|---|
| 六步换相 | 22.2 mA | **13.3 mA** | −3 ～ 60 mA |
| FOC | 23.1 mA | **4.3 mA** | 15 ～ 32 mA |

**解释**：六步换相是"电压模式"，两相之间加的平均电压 D·Vbus 是恒定的，电流 = (D·Vbus − 线反电动势)/(2R)。
GM2804 的反电动势是正弦波，导通的两相之间的线反电动势在扇区**中间最大**（悬空相过零时），在扇区**两头最小**，
所以电流在扇区中间被"压"下去、两头冒上来，每 60° 电角度起伏一次。这比 sin(超前角) 带来的 87%～100% 起伏大得多，
是正弦反电动势电机用六步换相时转矩脉动的主要来源。梯形反电动势的 BLDC 线反电动势在导通区间是平的，就没有这个问题。

**局限**：空载电流只有约 20～40 mA，和各相的零点偏差（约 ±10 mA）在同一量级，单看三相电流的方波形状不够清楚；
iq 的结论靠分箱平均和扇区折叠才看出来（原始 40 ms 波形的噪声标准差约 35 mA，两种方式看不出区别）。
以后可以给转子加一点摩擦负载（电流到 0.1～0.2 A）再测一次，方波和正弦的区别会更直观。
