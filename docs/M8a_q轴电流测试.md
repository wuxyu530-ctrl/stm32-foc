# M8a：q 轴电流测试（为速度环测机械参数）

> 2026-10-31 上板。代码 `APP_M8A_IQ_SPIN`（`main.c`，【Claude 代写，待复核】），复用 M7 的 ①～④。

## 1. 目的

速度环的被控对象是 iq → ω（电流环足够快，看成 1）：

```
J·dω/dt = Kt·iq − B·ω − Tc        Kt = 1.5 · p · ψf
传递函数（忽略 Tc）：ω / iq = Kt / (J·s + B)
```

和电流环 1/(L·s + R) 同形：J ↔ L（阻止变化），B ↔ R（消耗），多一个增益 Kt。
做法也同 M4b/M4c：先不接速度 PI，手动给固定 iq，看转速怎么变。

## 2. 流程

①～④ 同 M7 → id = 0、iq = 0.1 A，电机加速 → 转速 > 1500 rpm 或 1.5 s 后 iq = 0，
电流环继续运行（id = iq = 0，不出力也不刹车），惯性滑行 → 回零矢量。每 2 ms 打印一行。

## 3. 结果

| 数据 | 文件 |
|---|---|
| run1：上限 3000 rpm，2350 rpm 时过流跳闸 | `data/m8a_iq0p1_run1_trip.txt` |
| run2：上限 1500 rpm，完整加速 + 滑行 | `data/m8a_iq0p1_run2.txt` |

**加速段**（run2，30～170 ms，iq 平均 0.097 A）：dω/dt = 803 rad/s²（run1：782）

**反电动势**：vq − R·iq 对电角速度 ωe 线性拟合，斜率 = ψf

| | ψf | 截距 |
|---|---|---|
| run1（0～2300 rpm） | 3.27 mWb | 0.03 V |
| run2（0～1500 rpm） | 3.11 mWb | 0.11 V |

取 ψf ≈ 3.2 mWb（±5%，用的是指令电压，含死区误差）→ **Kt = 1.5 × 7 × ψf ≈ 0.034 N·m/A**。
换算 Kv（线电压峰值）≈ 240 rpm/V，与 2804 云台电机标称量级一致。

**滑行段**（iq ≈ 0）：减速度对转速线性拟合

```
dω/dt = −0.97·ω − 183   [rad/s²，ω 为机械角速度 rad/s]
→ B/J = 0.97 s⁻¹（机械时间常数 J/B ≈ 1 s），Tc/J = 183 rad/s²
```

摩擦以库仑摩擦为主：Tc 相当于 iq ≈ 22 mA 的转矩；1500 rpm 时粘滞部分约占 45%。

**J**：加速段必须扣除摩擦，否则 J 会估大约 35%：

```
803 = (Kt/J)·0.097 − 183 − 0.97 × 82（加速段平均转速约 82 rad/s）
→ Kt/J ≈ 1.1 × 10⁴ rad/s²/A → J ≈ 3.0 × 10⁻⁶ kg·m²
```

| 参数 | 值 | 设计速度环时怎么用 |
|---|---|---|
| Kt/J | ≈ 1.1 × 10⁴ rad/(s²·A) | 决定 Kp_ω（类似电流环里的 1/L） |
| B/J | ≈ 1 s⁻¹ | 极点在 0.15 Hz，远低于速度环带宽，近似为纯积分 |
| Tc | ≈ 22 mA 的 iq | 相当于恒定负载扰动，靠速度 PI 的积分消除 |

## 4. 过流跳闸（run1）：待解决

run1 在 2350 rpm、vq ≈ 6.0～6.25 V（接近 v_max = 6.32 V）时触发 2 A 过流保护。
跳闸前 iq 只有约 0.1 A，角度自检误差 1～2°，真实电流不可能超过 2 A。

**最可能的原因：高调制区低边采样窗口太短**。占空比最大的那一相，下管导通只剩约 2 µs（d_max = 0.956，
这个值是估计的，一直没有实测），运放输出还没稳定就被采样，读到错误的大电流。
佐证：跳闸前 iq 读数开始出现异常跳动（312 ms 时 0.321 A，前后 0.03～0.08 A）。

**处理**：
- 暂时：M8a 转速上限 1500 rpm（vq ≈ 4 V），避开高调制区
- 根治（速度环做高速之前）：实测采样窗口（M1b），修正 d_max；
  或在高调制区只用下管导通时间最长的两相，第三相由 ia + ib + ic = 0 算出
