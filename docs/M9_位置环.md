## 1. 结构

```
θ_ref ─►(−)─► 位置 P ─► ω_ref ─► 速度 PI ─► iq_ref ─► 电流环 ─► 电机 ─► θ
           ▲      （限幅 300 rpm）                                      │
           └──────────────── 编码器累计位置 ◄────────────────────────────┘
```

- 位置环、速度环都在中断里每 1 ms 跑一次，读同一个编码器计数
- 位置以**机械角**计（rad），以位置环启动时刻为 0°，分辨率 360°/4096 ≈ 0.088°

## 2. 设计

| 项 | 取值 | 理由 |
|---|---|---|
| 控制器 | **纯 P**（复用 `core/pi.c`，ki = 0） | 被控对象（速度环 + 转速积分成位置）本身含积分，P 控制阶跃无稳态误差 |
| Kp_pos | 2π × 10 = 62.8 (rad/s)/rad | 开环 ≈ Kp_pos/s，穿越频率 10 Hz，约为速度环 50 Hz 的 1/5（串级：外环比内环慢） |
| 输出限幅 | ±300 rpm | 90° 阶跃时 Kp × 误差 ≈ 940 rpm，限幅后匀速走，避免速度环和电流环长时间饱和 |

**负载转矩为什么不会留下位置误差**：恒定负载由速度环的积分抵消；静止时速度环的积分要不再变化，速度误差必须为 0，
也就是 ω_ref = 0，所以位置误差 = 0。

## 3. 单元测试（`test/test_foc_position.c`，三环 + 电机模型 + 编码器量化）

| 测试 | 结果 |
|---|---|
| 累计位置：方向、回绕、多圈 | 通过 |
| 纯 P 与限幅 | 通过 |
| 0 → 90° 阶跃 | **112 ms 进入 ±0.5°，无超调**（峰值 90.06°），最高转速 317 rpm，iq 顶到 0.4 A |
| 保持 0° 时突加负载（相当于 0.05 A） | **只被推开 0.42°**，1 s 后回到 0° |

## 4. 上板流程（`APP_MODE = APP_M9_POSITION`）

| 步骤 | 内容 | 串口输出 |
|---|---|---|
| ①～④ | 同 M7 | 同 M7 |
| ⑤a | 位置环接管，以当前位置为 0°，保持 0.5 s | `[5a] hold 0 deg: theta=... iq_ref=...` |
| ⑤b | 0 ↔ 90° 每 500 ms 往返，叠加 10 次（10 s） | 无 |
| ⑤c | **保持 0° 共 15 s，每 100 ms 打印一行。这段时间可以用手指轻推转子外壳** | `t_s, err_deg, w_rpm, iq_ref_A` |
| ⑥ | 停，打印 300 行 CSV | `k, t_ms, th_ref_deg, th_deg, w_rpm, iq_ref_A` |

**⑤c 用手推时**：转矩上限只有 Kt × 0.4 A ≈ 0.014 N·m，非常小，很容易推动，不会伤手。
推开后能感觉到它往回"拽"，松手后回到 0°；串口里 err_deg 会先变大再回到 0 附近，iq_ref 会跟着变化。

## 5. 预期与对比

- 阶跃响应应接近单元测试：约 100 ms 到位，没有明显超调，稳态误差在 ±1 个计数（0.09°）以内
- 电机现在刚性固定：如果速度环的约 100 Hz 振铃已经消失，位置曲线会很干净；如果还在，位置曲线上会叠加小幅振荡
