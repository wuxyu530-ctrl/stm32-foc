| 探针与箭头 | 乘积按转速拆成箭头首尾相加；静止箭头积分 c·T 一直走（极点），转动箭头积分绕圆心 −c/(jω₀)、半径 \|c\|/\|ω₀\|；F(s) = 各圆心之和；静止箭头方向 = 初相位 | ✅ |
| 山坡图 | 高度 = \|F(s)\|；柱子 = 极点（成分），山坡无独立信息，坑 = 零点（抵消）；虚轴切面 = 频谱，峰位置 ≈ 极点虚部、半功率带宽 = 2×极点实部 | 🔶 |
| 极点零点 | 信号：极点 = 成分，零点 = 各成分抵消处（随相位移动）；系统：极点 = 自然响应模式，零点 = 挡住的输入模式；输出极点 = 系统极点 + 输入极点（对消、重极点例外）；自然响应 vs 强迫响应 | 🔶 |
| 带宽与闭环极点 | 面试版：延迟 ≈ 1.5 Ts 是固定时间，带宽越高，穿越频率处相位落后越大 → 相位裕度小 → 超调振铃 → 振荡，故取 PWM 的 1/10~1/20；s 平面：有延迟时带宽增大，闭环极点离原点更远（快）且更靠近虚轴（阻尼小），无延迟则只沿负实轴移动。深层原因（长度条件 \|p\| = ω_bw·e^(σTd)、角度条件 夹角 = ω_d·Td、781 Hz 相撞、3.33 kHz 到虚轴）先记规则，见 https://claude.ai/artifact/2js7QruZZ1YFfYZn3GYKJV | 🔶 |
