## 1. 环路与误差

电流环就是一个圈：

```
目标电流 ──►(−)──► 误差 ──► PI ──► 电压 ──► 延迟 ──► 电机 ──► 实际电流
             ▲                                                    │
             └───────────────────── 测量 ◄────────────────────────┘
```

- **误差** = 目标电流 − 实际电流，就是 PI 计算时用的那个量。
- 实际运行时，误差里混着各种成分：目标变化、负载扰动、采样噪声……每一种都可以拆成许多不同频率的正弦叠加。
- 分析稳定性时说的"1 kHz 正弦误差"，指的是**误差里某一个频率成分**，不是说目标电流是正弦，也不关心它是怎么来的。
- 做法：设想在误差处把环路剪断，注入一个某频率的小正弦，让它走一圈（PI → 延迟 → 电机 → 测量），看回来的信号变大还是变小、落后了多少度。这叫**开环频率响应**，画出来就是 Bode 图。工业上真的这样测。

**为什么可以一个频率一个频率地看？** 因为 PI、延迟、RL 电机都是**线性系统**：

1. 正弦进，正弦出，频率不变，只改变幅度和相位；
2. 叠加原理：几个频率一起输入，输出等于各自输出之和。

所以每个频率单独判断，每个都衰减，整体就稳定。注意：限幅、死区是非线性的，这套分析对它们只能近似。

**为什么稳定性和扰动来源无关？** 如果某个频率走一圈正好落后 180°、放大倍数正好为 1，回来的信号经负反馈取负后和原信号一模一样，它会"自己生出自己"。从此即使外界扰动消失也会一直振下去。扰动只负责"点火"，不稳定是环路自身的性质。现实中噪声永远存在，所以不稳定的环路一定会振起来。

## 2. 记号 s：为什么求导、积分可以像乘除一样算

- `s` 表示对时间求导，`1/s` 表示积分。
- 对指数信号 e^(st)，求导**恰好等于**乘以 s：

```
d/dt e^(st) = s × e^(st)       求导 = 乘以 s
∫ e^(st) dt = e^(st) ÷ s       积分 = 除以 s
```

  M4c 里见过同样的事：g = e^(−t/τ)，dg/dt = −g/τ。

- 任何信号都可以拆成这种成分（拉普拉斯变换），对每个成分来说，每个方块只是"乘以一个数"。所以可以通分、约分、交换顺序，不分左右。前提：线性系统、初始状态为 0。

电机方程验证：

```
V = L·di/dt + R·i
代入 i = e^(st)：V = (Ls + R)·i     →    i = V / (Ls + R)    真正的除法
```

PI 控制器：

```
V = Kp·e + Ki·∫e    →    V = (Kp + Ki/s)·e
```

**正弦对应 s = jω**（j·j = −1，乘 j 表示相位超前 90°）：

```
求导 = 乘 jω：幅度 × ω，超前 90°
积分 = 除 jω：幅度 ÷ ω，落后 90°
```

**ω 是什么**：角频率，ω = 2πf。f 是每秒转几圈，ω 是每秒转多少弧度（一圈 = 2π）。sin(2πft) = sin(ωt)。公式里用 ω 是因为求导和积分自然带出 ω，不用到处写 2π。ω_bw = 2π × 带宽。

## 3. 积分为什么落后 90°

**水箱比喻**：输入 = 进水速度（正进负出），积分 = 水位。

水位最高不是在进水最快时，而是在进水**刚停下来**（输入回到 0）的那一刻。只要还在进水，水位就还在涨。

| 时刻 | 输入（进水速度） | 积分（水位） |
|---|---|---|
| 0 | 0，开始变正 | 最低，开始涨 |
| T/4 | **最大** | 涨得最快，还没到顶 |
| T/2 | 回到 0 | **最高** |
| 3T/4 | 最小 | 降得最快 |
| T | 回到 0 | 最低 |

输入在 T/4 达到峰值，积分在 T/2 达到峰值，晚了四分之一周期 = **90°**，与频率无关。

用控制的话说：误差在 T/4 最大，本应在这时给出最强的纠正，但积分要到 T/2 才最大，**纠正晚了 90°**。

- **幅度**：频率越高，每半个周期进水时间越短，水位涨得越低，幅度 = A ÷ ω。
- **不会无限累积**：纯正弦正负半周抵消，水位只是上下摆动。只有长期不为零的误差（稳态误差）才会让积分持续增大，这正是 I 项消除稳态误差的原因。

## 4. 环路增益（放大倍数）

**定义**：误差里的某个频率成分走一圈回来，幅度变成原来的几倍。小于 1 表示缩小。

各环节：

| 环节 | 幅度 | 相位 |
|---|---|---|
| 延迟 Td | × 1 | 落后 360°·f·Td |
| 测量 | × 1（假设准确） | 0 |
| PI × 电机（极零对消后，见 §8） | Kp / (ωL) | 落后 90° |

PI × 电机 = Kp/(L·s)：先乘 Kp，再交给电感积分。电感就是那个"水箱"：电流 = 电压的累积 ÷ L。

```
放大倍数 = Kp / (ωL) = (L·ω_bw) / (ω·L) = ω_bw / ω = f_bw / f = 1000 / f
```

L 被约掉，这正是 Kp 取 L·ω_bw 的目的：让放大倍数恰好在带宽处等于 1。

用真实数值（误差幅度 1 A，Kp = 5.5 V/A，L = 0.88 mH）：

| 频率 | PI 输出电压 | 电感产生的电流 V/(2πfL) | 放大倍数 |
|---|---|---|---|
| 500 Hz | 5.5 V | 2 A | 2 |
| 1 kHz | 5.5 V | 1 A | 1 |
| 2 kHz | 5.5 V | 0.5 A | 0.5 |

同样的电压，频率越高，电压来回越快，电感里的电流来不及涨起来。

**放大倍数大于 1 不是坏事**：放大的是纠正信号，它回来时被**减掉**（负反馈）。

```
闭环后剩下的误差 ≈ 原误差 ÷ (1 + 放大倍数)
```

| 频率 | 放大倍数 | 误差被压到 |
|---|---|---|
| 10 Hz | 100 | 约 1% |
| 100 Hz | 10 | 约 1/11 |
| 1 kHz | 1 | 约 1/2 |

低频放大倍数大，所以电流环能精确跟踪低频目标、压住低频扰动。

## 5. 相位裕度

### 定义

> 在环路增益 = 1 的频率上，误差的这个频率成分走一圈总共落后的角度，离 180° 还差多少。

- **为什么和 180° 比**：落后 180° = 晚了半个周期，波峰对上波谷，负反馈变成助推。
- 它是**角度**，不是某段固定时间。同样的 90° 积分落后，100 Hz 时相当于 2.5 ms，1 kHz 时相当于 0.25 ms，所以必须用角度统一。

### 公式

```
相位裕度 = 180° − 90°（积分）− 360° × f_bw × Td
        = 90° − 360° × f_bw × Td
```

1 kHz、75 µs：180 − 90 − 360 × 1000 × 0.000075 = **63°**

| 带宽 | 延迟落后（Td = 75 µs） | 相位裕度 |
|---|---|---|
| 500 Hz | 13.5° | 76.5° |
| 1 kHz | 27° | 63° |
| 2 kHz | 54° | 36° |
| 4 kHz | 108° | −18°（发散） |

带宽处闭环幅度 ≈ 1/(2·sin(PM/2))：PM 越小，在带宽附近出现的"鼓包"（谐振峰）越高，阶跃响应振铃越明显。

### 为什么只看环路增益 = 1 的那个频率

振荡要**同时满足**两个条件：

1. 落后 ≥ 180°（变成助推）
2. 放大倍数 ≥ 1（助推不会越走越小）

随着频率升高，两者变化方向相反：

- 频率越高，周期越短，固定延迟占周期比例越大 → **落后越多**
- 频率越高 → **放大倍数越小**（1000/f）

| 频率 | 放大倍数 | 落后 = 90° + 360°·f·75 µs | 结果 |
|---|---|---|---|
| 250 Hz | 4 | 97° | 强负反馈 |
| 500 Hz | 2 | 104° | 强负反馈 |
| **1 kHz** | **1** | **117°** | **分界点，余量 63°** |
| 2 kHz | 0.5 | 144° | 每圈减半 |
| 3.3 kHz | 0.3 | 180° | 已变助推，但每圈只剩 30%，自行衰减 |

推理：

- 放大倍数 < 1 的频率：就算变成助推，每圈都变小，不用考虑。
- 放大倍数 ≥ 1 的频率：需要检查落后是否到 180°。其中落后最多的是频率最高的那个，也就是放大倍数**刚好等于 1** 的频率。
- 只要它离 180° 有余量，其他放大倍数 ≥ 1 的频率落后更少，更安全。

**所以环路增益 = 1 的频率是最坏情况，只检查它就够了。**

反例：带宽设成 4 kHz，放大倍数 = 4000/f。在落后 180° 的 3.3 kHz 处，放大倍数 = 1.2 > 1，两个条件同时满足，越振越大。

## 6. 延迟：为什么是 1.5 Ts

```
1.5 Ts = 1 Ts（计算更新延迟） + 0.5 Ts（PWM 零阶保持延迟）
```

**1 Ts：算出来的电压要等下一个周期才生效（通用方案）**

```
周期 k 开始          周期 k+1 开始
   ▼ 采样电流           ▼ 新占空比生效
   └─ 中断算 PI、写 CCR ─┘
      （写入预装载寄存器，等更新事件才生效，防止周期中途改占空比导致波形错乱）
```

**0.5 Ts：PWM 输出的是台阶**

PI 想要平滑变化的电压，PWM 每个周期只能输出一个固定平均值并保持一整个周期。台阶代表的是周期起点算出的值，却一直保持到终点，平均比平滑曲线**落后半级 = 0.5 Ts**。这叫零阶保持器（ZOH）延迟，任何"算一次、保持一周期"的数字控制都有。

**本板实际约 1 Ts = 50 µs**

- 中心对齐 PWM，在计数器顶点采样（此时三相都是下管导通，零矢量 000，电流流过下桥臂采样电阻；且离开关沿最远，噪声最小）。
- 采样后约**半个周期**就到更新事件，实测纯延迟 t0 ≈ 23 µs ≈ 0.5 Ts。
- 再加 ZOH 的 0.5 Ts = 25 µs，合计约 50 µs。

```
本板：   25 µs（等更新事件）+ 25 µs（ZOH）≈ 50 µs ≈ 1 Ts
通用：   50 µs（等一整个周期）+ 25 µs（ZOH）= 75 µs = 1.5 Ts
```

M4c 阶跃只测出 23 µs、看不到 ZOH：阶跃电压从第一个周期起就是满的，没有"台阶跟不上曲线"的问题。ZOH 的半周期只在电压持续变化时才体现出来。

Simulink 先用 75 µs 设计（保守），实际硬件延迟更小，表现只会更好。

| 延迟 | 1 kHz 带宽时相位裕度 |
|---|---|
| 75 µs | 63° |
| 50 µs | 72° |

## 7. 带宽

### 定义是固定的

> 输入不同频率的正弦，从低频往高频扫，**闭环**输出幅度降到满幅的 70.7%（1/√2，即 −3 dB）时的频率。

### 数值是系统的性质，但"系统"包含了什么很关键

| 系统 | 带宽 | 谁决定 |
|---|---|---|
| 电机本身（电压 → 电流） | 580 Hz | L、R，固有，改不了 |
| 电流环（目标 → 实际，含 PI） | 1 kHz | Kp、Ki，**设计出来的** |

电流环里包含我们设计的 PI，改 Kp 就是改系统，带宽也就变了。设置带宽 = 用 Kp 把 70.7% 那个点放到想要的频率上，与定义不矛盾。

加了 PI 后电流环可以比电机本身更快（1 kHz > 580 Hz）：PI 在需要时给出比稳态更大的电压，推着电感里的电流变化。

但能设多高受物理限制：上限由延迟决定，延迟由 PWM 频率决定（§9）。

> 电流环带宽是**人为选择**的，但只能在**物理允许**的范围内选。

### 电机自身带宽 R/(2πL) 的推导

```
i/V = 1/(Ls + R) = (1/R) × 1/(τs + 1)，  τ = L/R
1/R 是低频满幅（电流 = 电压/R），带宽看相对满幅，只看 1/(τs + 1)

代入 s = jω：  幅度 = 1 / |jωτ + 1| = 1 / √(1 + (ωτ)²)
令其 = 1/√2：  1 + (ωτ)² = 2  →  ωτ = 1  →  ω = R/L  →  f = R/(2πL)

f = 3.21 / (2π × 0.00088) ≈ 580 Hz
```

**物理意义**：电阻的阻碍是 R（与频率无关），电感对正弦的阻碍是 ωL（感抗，频率越高越大）。电感电压超前电流 90°、电阻电压与电流同相，两者垂直，总阻碍 = √(R² + (ωL)²)。

| 频率 | 感抗 ωL | 总阻碍 | 电流相对满幅 |
|---|---|---|---|
| 很低 | ≈ 0 | ≈ R | ≈ 100% |
| 580 Hz | = R | √2·R | 70.7% |
| 5.8 kHz | 10R | ≈ 10R | ≈ 10% |

**带宽就是感抗增长到与电阻相等的频率。**

通用结论：任何一阶系统 1/(τs + 1)，带宽 = 1/(2πτ)。

### 带宽反映什么

系统能跟上多快的变化，三种说法是同一件事：

| 角度 | 带宽 1 kHz 时 |
|---|---|
| 跟踪 | 远低于 1 kHz 的目标变化跟得好，远高于的跟不上 |
| 速度 | 阶跃响应时间常数 1/ω_bw = 0.16 ms |
| 抗扰 | 低于 1 kHz 的扰动被压到 1/(1 + f_bw/f) |

### 带宽 vs 穿越频率

| 名称 | 定义 |
|---|---|
| 穿越频率 | **开环**（环路）增益 = 1 的频率，相位裕度在这里读 |
| 带宽 | **闭环**输出降到 70.7% 的频率 |

本设计（极零对消，环路 = ω_bw/s）在不考虑延迟时两者完全相等，所以讨论时常混用。加上延迟后有偏差，相位裕度越小偏差越大。

### 常见误解（我自己犯过的）

- ✗ 带宽是"输出落后目标"的频率 → ✓ 是幅度**变小**到 70.7% 的频率
- ✗ 带宽是硬上限，超过就完全跟不上 → ✓ 超过后幅度逐渐变小，不是突然消失
- ✗ 带宽是被 70.7% 定死的固有值 → ✓ 定义固定，数值由系统决定，而电流环这个系统包含 PI，所以可以设计

## 8. PI 参数：Kp = L·ω_bw，Ki = R·ω_bw 怎么来的

### 第 1 步：目标

希望 PI × 电机 正好等于一个**纯积分器** ω_bw/s：

- 落后永远 90°，给延迟留出最多的余量
- 放大倍数 = f_bw/f，正好在选定的带宽处等于 1
- 闭环是干净的一阶响应，不超调

### 第 2 步：凑系数（核心）

```
环路 = PI × 电机 = (Kp + Ki/s) × 1/(Ls + R)

PI 通分：Kp + Ki/s = (Kp·s + Ki) / s

环路 = 1/s × (Kp·s + Ki) / (Ls + R)
             └──── 希望等于常数 ω_bw ────┘

即：Kp·s + Ki = ω_bw·(Ls + R) = ω_bw·L·s + ω_bw·R

比较 s 的系数：  Kp = ω_bw × L
比较常数项：     Ki = ω_bw × R
```

本质：让 PI 分子 (Kp·s + Ki) 和电机分母 (Ls + R) 成比例，一上一下约掉，比例系数就是 ω_bw。

这叫**极零对消**：PI 的零点（s = −Ki/Kp）与电机的极点（s = −R/L）重合，条件是 Ki/Kp = R/L，即 PI 的积分时间 Ti = Kp/Ki 等于电机时间常数 τ。

### 第 3 步：物理意义

**Kp 管电感，决定纠正多快。** 希望误差在时间 1/ω_bw 内被纠正，电流变化速度需 ≈ 误差 × ω_bw；电感要求电压 = L × 电流变化速度，所以电压 = L·ω_bw·误差，即 Kp = L·ω_bw。因果是：**先选定想要多快（带宽），再由电感算出需要多大的 Kp。** L 越大，电流越难改变，需要的 Kp 越大。

**Ki 管电阻，保证最终无误差。** 稳态时电感无压降，维持电流 i 需要持续提供 R·i 的电压。误差为 0 时 Kp·e = 0，这部分电压只能由积分项累积并保持。

### 第 4 步：闭环

```
环路 G = ω_bw/s
闭环 = G/(1+G) = ω_bw/(s + ω_bw) = 1/(s/ω_bw + 1)
```

形状与 RL 电路 1/(τs + 1) 完全相同，只是时间常数从电机的 0.27 ms 变成我们选定的 1/ω_bw = 0.16 ms。阶跃响应是指数曲线，不超调（不计延迟时）。在 f_bw 处幅度 = 1/|j + 1| = 70.7%，与带宽定义吻合。

### 第 5 步：数值

```
ω_bw = 2π × 1000 = 6283 rad/s
Kp   = 0.88 mH × 6283 ≈ 5.5 V/A
Ki   = 3.21 Ω  × 6283 ≈ 2.0×10⁴ V/(A·s)
Ki·Ts = 2.0×10⁴ × 50 µs ≈ 1.0 V/A     代码里积分每周期加 Ki·Ts·误差
```

### 弱点

依赖准确的 L、R：

- R 随温度升高（铜约 +0.4%/°C）：零点对不准，留下一个慢尾巴，由积分慢慢消掉，影响不大。
- L 估错：带宽按比例偏移。L 估大 → Kp 偏大 → 带宽变高 → 相位裕度变小。所以 L 要测准（待办：上电复测 L）。

## 9. 带宽怎么选：PWM 频率的 1/10 ~ 1/20

**带宽越大越危险**：延迟是固定时间，带宽越大，带宽频率的周期越短，延迟占周期比例越大，落后越多，相位裕度越小。

**带宽越小越慢**：

- Kp = L·ω_bw 小 → 同样误差只给出小电压 → 电感里电流涨得慢（误差 1 A：1 kHz 带宽给 5.5 V，0.16 ms 涨到；100 Hz 带宽给 0.55 V，1.6 ms）
- 闭环时间常数 1/ω_bw 大
- 扰动压不住（100 Hz 扰动：1 kHz 带宽压到 1/11，100 Hz 带宽只压到 1/2），表现为转矩脉动和噪声
- 外层速度环带宽一般只能取电流环的 1/5 ~ 1/10，电流环慢，整个系统都慢

**取舍**：在保证足够相位裕度的前提下，带宽尽量取大。

**为什么是"PWM 频率的几分之一"**：延迟 = 1.5 Ts = 1.5/f_pwm，代入：

```
相位裕度 = 90° − 540° × (f_bw / f_pwm)
```

相位裕度只取决于两者的**比值**：

| f_bw / f_pwm | 相位裕度 | 评价 |
|---|---|---|
| 1/20 | 63° | 稳，几乎不超调 |
| 1/10 | 36° | 能用，明显振铃 |
| 1/6 | 0° | 临界振荡 |

想要更高带宽，只能提高 PWM 频率（缩短延迟），代价是开关损耗增加。
