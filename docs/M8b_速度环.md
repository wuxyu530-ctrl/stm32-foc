## 1. 目标与约束

**目标**：机械转速 ω 跟随 ω_ref，无稳态误差（恒定摩擦也要消除）。

| 约束 | 数值 | 影响 |
|---|---|---|
| 电流环带宽 | 1 kHz | 速度环要低得多（1/10～1/20），才能把电流环看成 ≈ 1 |
| 测速 | 每 1 ms 用编码器计数差算一次，1 个计数 = 1.53 rad/s ≈ 14.6 rpm | 有延迟、有量化噪声，带宽不能太高；不用 D 项 |
| iq 上限 | 0.4 A | 电源限流 0.5 A，留余量；大阶跃时会饱和 |
| 转速上限 | 1500 rpm | 高调制区采样窗口不足会误报过流（`M8a_q轴电流测试.md` §4） |

## 2. 被控对象（M8a 实测）

```
ω / iq = (Kt/J) / (s + B/J) = 11000 / (s + 0.97)      另有恒定摩擦 Tc/J = 183 rad/s²
```

| 符号 | 含义 | 值 |
|---|---|---|
| Kt/J | 每安培 iq 产生的角加速度 | 1.1 × 10⁴ rad/(s²·A) |
| B/J | 粘滞摩擦 | 0.97 /s（极点 0.15 Hz） |
| Tw | 速度环周期 | 1 ms |
| ωc | 目标穿越频率 | 2π × 50 Hz = 314 rad/s |

在 50 Hz 附近，被控对象 ≈ 11000/s（纯积分）。

## 3. 设计

**Kp**：被控对象 ≈ (Kt/J)/s，令开环增益在 ωc 处为 1：

```
Kp = ωc / (Kt/J) = 314 / 11000 = 0.0286 A/(rad/s)
```

（对照电流环 Kp = L·ωc：那里高频时被控对象 ≈ 1/(L·s)。）

**Ki**：PI 零点 ωz = Ki/Kp 放在 ωc/4：

```
Ki = Kp · ωc/4 = 0.0286 × 78.5 = 2.24 A/rad，    Ki·Tw = 0.00224
```

为什么不像电流环那样用零极点抵消（ωz = B/J）：积分时间常数会变成约 1 s，恒定摩擦带来的误差要 1 s 才消除。
放在 ωc/4，代价是 ωc 处有 atan(1/4) ≈ 14° 的相位滞后。

**延迟**：测速是过去 1 ms 的平均（等效延迟 0.5 ms）+ PI 输出保持 1 ms（0.5 ms）+ 电流环一阶滞后（0.16 ms）。

| 指标 | 结果（`sim/speed_loop_design.m`、Python 交叉验证） |
|---|---|
| 穿越频率 | 51 Hz |
| 相位裕度 | 55° |
| 增益裕度 | 12.5 dB（208 Hz） |

## 7. Simulink 模型（`sim/speed_loop_dt.slx`，待搭）

```
Step(600→700 rpm, 换成 rad/s) → Sum → Discrete PID(P、I；Kp、Ki；Ts = 1e-3；前向欧拉；
限幅 ±0.4，钳位抗饱和) → Transfer Fcn 1/(tau_i·s+1) → Gain Kt/J → Sum(− Tc/J 常数) →
Transfer Fcn 1/(s + B/J) → ω ─┬─► Scope
                              └─► Integrator（→ 角度）→ Quantizer(2π/4096) → Zero-Order Hold(1e-3)
                                  → Difference / Ts（= 测得转速）→ 回到第一个 Sum 的负端
```

测速部分用"积分成角度 → 量化 → 每 1 ms 差分"来模拟编码器，和固件完全同构。
初始状态要设成 600 rpm 稳态（积分器初值、PID 积分初值 = 0.022 A），否则会先看到 0→600 的启动过程。

## 9. 排查（2026-10-31）

### 9.1 Kt/J 没有测错：多电流点拟合

`data/m8a_multi_iq.txt`：一次上电依次用 iq = 0.1、0.2、0.3 A 加速，每次加速后滑行（iq ≈ 0）。
在同一转速区间 400～1100 rpm 里拟合"加速度对 iq"的直线（6 个点：3 个加速 + 3 个滑行）：

| iq (A) | 加速度 (rad/s²) | 直线拟合值 | 残差 |
|---|---|---|---|
| 0.0999 | 794 | 809 | −15 |
| 0.2029 | 1883 | 1927 | −44 |
| 0.2944 | 2956 | 2921 | +35 |
| ≈ 0（三次滑行） | −257 / −262 / −252 | ≈ −260 | < 25 |

```
加速度 = 10860 × iq − 276      → Kt/J ≈ 1.09 × 10⁴（只用 3 个加速点：1.11 × 10⁴）
```

三点在一条直线上，Kt 不随电流变化；斜率和 M8a 的 1.1 × 10⁴ 一致。**被控对象的参数是对的。**

### 9.2 真正的线索：转矩一跳变，测得的转速就"振铃"

用 1 ms 分辨率看 iq = 0.3 A 那次刚启动的几十毫秒（每毫秒转速增量，稳态应为 28 rpm/ms）：

```
t = 4～5 ms：  +44 rpm/ms   ← 比稳态大 50%
t = 10～11 ms：+22 rpm/ms   ← 比稳态小
之后约 29 rpm/ms 附近
```

转矩是阶跃，加速度却先冲高、再回落、再稳定，周期约 10 ms。M8b 阶跃里也是同样的形状
（峰值 5 ms、谷值 9 ms）。而且 M8b 里 iq 的变化解释不了测得转速的起伏：
按 iq 积分得到的转速增量和测得的对不上，测得的转速明显多了一个约 100 Hz 的振荡。

**最可能的原因：电机固定得不够硬，出现了机械谐振（双惯量系统）。**
编码器测的是转子**相对定子**的角度。转矩作用在转子上，反作用转矩作用在定子上；
如果定子（连同底座）是用胶带之类的软连接固定的，定子会被反向扭转、再弹回来，
相对转速里就叠加了一个振荡。这个振荡频率（约 100 Hz）离速度环穿越频率（51 Hz）很近，
吃掉了相位裕度，所以阶跃响应超调大、出现衰减振荡。

**验证方法**：把电机刚性固定（螺丝、夹具），重跑 M8b 和这个多电流点测试。
若振荡明显减弱或频率变高，即可确认。
