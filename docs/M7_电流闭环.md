## 1. 目标

第一次让电流环在板子上闭环运行，并且**和仿真对比**：

> 转子不转（d 轴电流把它锁在 θe = 0），d 轴电流目标 0.2 A → 1.0 A 阶跃，
> 重复 64 次叠加平均，串口输出波形，与 `sim/current_loop_dt_board.slx` 对比。

为什么先测 d 轴、转子不转：和 M4c 测电感的条件一样（没有反电动势、没有 dq 耦合），
单轴 Simulink 模型可以直接对照；d 轴电流不产生转矩，转子不会跑掉，最安全。

## 3. 中断里的一步（每 50 µs）

```
ADC 注入组完成中断（current_sense.c）
  → 三相电流 i_abc [A]
  → cs_on_sample()（main.c）
      过流检查（任一相 > 2 A 立即关 MOE）
      case CTL_CURRENT:
        θe = theta_e_from_encoder()           读 TIM4，换算电角度
        sin/cos(θe)
        id_ref：阶跃测试时按周期切换 0.2 / 1.0 A
        foc_cur_step()                         core/foc_current.c
          Clarke → Park → id, iq
          vd = PI_d(id_ref − id)，限幅 v_max
          vq = PI_q(iq_ref − iq)，限幅 √(v_max² − vd²)     ← d 轴优先
          反 Park → SVPWM → 三相占空比
        pwm_set_duty()                         写 CCR，约半个周期后生效
        记录 id、iq、vd 到叠加数组
```

### 3.1 电角度

```
θe = 2π · frac( ENC_DIR · 极对数 · (cnt − cnt0) / 4096 )
```

| 量 | 值 | 来源 |
|---|---|---|
| 极对数 | 7 | M4a-2 实测 7.004 |
| ENC_DIR | −1 | M4a-2：θe 增大时计数减小 |
| cnt0 | 每次上电重新测 | 开环把转子拉到 θe = 0 时的计数 |

frac() 取小数部分，把"走了好几圈电角度"折回 [0, 2π)。

### 3.2 电压上限 v_max

```
v_max = (2·d_max − 1) · Vbus / √3 = (2 × 0.956 − 1) × 12 / √3 ≈ 6.32 V
```

比理想的 6.93 V 小，是因为占空比最多到 d_max = 0.956（低边采样需要下管导通时间）。
用它给 PI 限幅，SVPWM 算出来的占空比天然不超过 d_max，不会被硬截断。推导见 `core/foc_current.h` §3。

## 4. 上板流程（main.c ①～⑥）

| 步骤 | 做什么 | 串口应看到 |
|---|---|---|
| ① 采样准备 | 运放、ADC、零点标定，启动编码器，开 PWM（零矢量） | `[1] ISR rate = 20000 /s` |
| ② 对齐 | 开环 0.8 V 把转子拉到 90° 再到 0°，记下 cnt0 | `[2] aligned: enc cnt0 = ...` |
| ③ 角度自检 | 开环依次拉到 90°、180°、270°、0°，比较指令角和编码器角 | 每行 `err` 在几度以内；**超过 20° 会自动停止，不进入闭环** |
| ④ 闭环保持 | 清积分，切到 CTL_CURRENT，id = 0.2 A、iq = 0，保持 0.5 s | `id ≈ 0.20`、`iq ≈ 0`、`vd ≈ 0.64 V`（= 3.21 × 0.2）、`vq ≈ 0` |
| ⑤ 阶跃 | id 目标每 10 ms 在 0.2 / 1.0 A 之间切换，叠加 64 次（约 0.64 s） | （无输出） |
| ⑥ 输出 | 关闭闭环，回零矢量，打印 CSV | `k, t_us, id_ref, id_A, iq_A, vd_V`，共 60 行 |

## 5. 预期结果（按板子时序模拟）

阶跃前稳态：id = 0.2 A，vd = 0.642 V。阶跃后：

| t (µs) | id 预期 (A) | vd 预期 (V) |
|---|---|---|
| 0 | 0.200 | 5.07 |
| 50 | 0.320 | 5.21 |
| 100 | 0.534 | 4.71 |
| 150 | 0.702 | 4.25 |
| 200 | 0.818 | 3.91 |
| 300 | 0.941 | 3.52 |
| 400 | 0.989 | 3.34 |
| 600 | 1.009（最高点，超调约 1.2%） | 3.23 |
| 稳态 | 1.000 | 3.21 |

注意 t = 0 那一行的电流还是 0.2 A：这一拍刚算出 5.07 V，半个周期后才加到电机上。

实测会和这张表有差别，正常的来源：
- **采样噪声**：单点约 ±0.12 A，叠加 64 次后约 ±0.015 A
- **死区**：实际电压比指令小一点（M4b 测出的 U0），稳态 vd 可能比 3.21 V 略大
- **L、R 的误差**：L 偏差会改变上升速度和超调
- **iq 不为 0**：小幅波动正常；如果明显偏离，说明电角度有偏差（d、q 混在一起了）

## 7. 安全

- 第一次运行：**RD6006 设 12 V、限流 0.5 A**。d 轴 1 A 时电机只消耗约 3.2 W，电源电流约 0.3 A，不会触发限流
- 软件过流保护：任一相超过 2 A 立即关断全部 MOS（`M3_I_TRIP`）
- 角度自检不通过时不会进入闭环
- 运行前转子周围不要有东西；运行中转子应几乎不动（被 d 轴电流锁住）

## 9. 出问题时怎么排查

| 现象 | 可能原因 |
|---|---|
| ISR rate 不是 20000 | ADC 触发配置变了（参考 7d0ec47 的 JEOS 修复） |
| 角度自检 err 很大、且 4 个点的误差在变 | 极对数错了 |
| 角度自检方向相反（90° 读成 270°） | ENC_DIR 符号错 |
| 闭环保持时 iq 明显不为 0、或转子慢慢转动 | 电角度零点有偏差，d 轴电流有一部分落在 q 轴上 |
| 阶跃时振荡、超调比预期大很多 | L 估大了（Kp 偏大）、延迟比预期长，或电流符号接反 |
| 一切换到闭环就过流跳闸 | 电流反馈符号错（正反馈），PI 越推越大 |
| id 稳态和目标差一截 | 积分没起作用，或零点标定偏了 |
