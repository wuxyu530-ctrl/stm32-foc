# 周末上板清单（2026-11-07～08）

> 没有示波器：所有结果都靠串口数据 + 叠加平均 / 分箱平均。每一步：切换 `APP_MODE` → 烧录 → 上电（RD6006 按 ON）→ 观察电机 → 串口采集 → 分析。

## 0. 每次上电前

- RD6006：12 V、限流 0.5 A；**用 ON/OFF 键开关，不带电插拔 XT30**
- 编码器由母线供电：**RD6006 不开输出，编码器就没电**，角度自检会失败
- 杜邦线接头缠胶带；线用扎带固定，远离转子
- 转子朝上、能用手自由拨动，周围没有东西

## 1. 固定电机

1. 卡尺量 4 根铜柱的间距（图纸 13.4 × 13.4 mm）和铜柱长度
2. 木板中间画孔位 → 2.5 mm 钻头打引导孔 → 3.2 mm 扩孔
3. M2.5 × 20 mm 螺丝从木板下面穿上来：螺丝头 → 弹垫 → 平垫 → 木板 → 铜柱。**确认拧进铜柱的长度小于铜柱长度**，不能顶到电机里（定子端 ≤ 4 mm）
4. 木板底面四角贴硅胶垫，两端压重物

## 2. 上板顺序

| # | 模式 | 时长 | 看什么 | 文档 |
|---|---|---|---|---|
| 1 | `APP_M8A_IQ_SPIN` | ~15 s | 多电流点测试：转矩阶跃后加速度还有没有 ~10 ms 周期的"振铃" | `docs/M8b_速度环.md` §9 |
| 2 | `APP_M8B_SPEED` | ~25 s | 600 ↔ 700 rpm 阶跃（叠加 40 次）：峰值是否回到设计的 ~720 rpm、9 ms 处的下冲是否消失 | `docs/M8b_速度环.md` §4、§8 |
| 3 | `APP_M10_SIXSTEP` | ~20 s | 转速 vs 占空比；六步方波电流 vs FOC 正弦电流；iq 脉动 | `docs/M10_六步换相.md` |
| 4 | `APP_M9_POSITION` | ~35 s | 0 ↔ 90° 阶跃；**最后 15 s 用手轻推转子** | `docs/M9_位置环.md` |
| 5 | 手机拍视频 | — | 位置环往返 + 手推回位；速度环恒速；六步和 FOC 声音对比 | — |

**判断谐振（第 1、2 步）**：

| 现象 | 结论 |
|---|---|
| 振铃消失，阶跃峰值接近 720 rpm、单调回落 | 确认是手按造成的机械谐振 → 简历速度环那一句可以补上 |
| 振铃还在但频率变高 | 仍是机械谐振，固定方式的刚度提高了 |
| 完全没变化 | 不是安装问题，往编码器 / 测速 / 模型方向查，考虑陷波滤波器 |

## 3. 出问题时

| 现象 | 处理 |
|---|---|
| 角度自检失败、编码器读数一直是 0 | RD6006 输出没开，或编码器线松了 |
| 过流跳闸 | 先断电，保存串口输出再分析 |
| 六步换相不转、抖动、反转 | 断电，保存 `[5a]` 那几行再分析 |
| 推送 GitHub 失败 | 本地已提交，不影响上板 |
